# 🛒 Superstore Sales Dashboard

## 📌 Overview

An interactive **Superstore Sales Dashboard** developed using **Microsoft Power BI** to analyze sales, profit, quantity, product performance, and regional trends.

The dashboard transforms raw sales data into meaningful business insights through interactive visualizations and KPIs.

## 🎯 Objectives

- Analyze sales and profit performance
- Track key business KPIs
- Identify top-performing sub-categories
- Analyze monthly sales and profit trends
- Understand geographical sales distribution

## 📊 Key KPIs

- **Total Sales:** ₹55.07M
- **Total Profit:** ₹5.22M
- **Total Quantity:** 19K
- **Profit Margin:** 9.47%

## 📈 Dashboard Features

- Sales by Sub-Category
- Sales by Category
- Monthly Sales & Profit Trends
- Geographical Sales Analysis
- Interactive Power BI visuals

## 🔍 Key Insights

- Chairs generated the highest sales among the sub-categories.
- Furniture contributed a significant share of overall sales.
- Sales and profit varied across different months.
- Sales were distributed across multiple regions of the United States.

## 🛠️ Tools & Skills

**Tools:** Microsoft Power BI, Power Query, DAX

**Skills:** Data Cleaning, Data Transformation, Data Analysis, Data Modeling, DAX Measures, KPI Development & Data Visualization

## 🚀 Project Outcome

This project demonstrates the use of Power BI to transform raw sales data into an interactive dashboard for business performance analysis.
